# Project preferences

## Pull requests
- **Open a new PR after every change.** When a change is committed and pushed, follow up with a new PR against `main` via `mcp__github__create_pull_request`. Don't wait to be asked.
- Don't bundle unrelated changes into the same PR.

## Branch
- Primary feature branch: `claude/website-redesign-planning-oj7XY`. Commit and push there unless told otherwise.
